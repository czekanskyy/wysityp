# SegmentedControl

Dwa do czterech wzajemnie wykluczających się wyborów: widok notatki, motyw, język.

- `role="radiogroup"`; strzałki przesuwają i od razu wybierają.
- Wybrany segment: `color-surface-raised` z `shadow-sm` na `color-surface-sunken`.
- Opcja tylko z ikoną (`iconOnly`) zachowuje etykietę jako nazwę dostępną i podpowiedź.

Kod: `SegmentedControl.svelte`.
