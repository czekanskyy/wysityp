# Card

Karta do przeglądów: szablony, ostatnie notatki, wyniki wyszukiwania.

- Opcjonalna plakietka z ikoną (`color-accent-soft`), tytuł 14px/600, linia meta w `color-text-muted`, krótki opis.
- Klikalna karta jest jednym przyciskiem; akcje w prawym górnym rogu leżą poza nim. Hover: `color-border-strong`, `shadow-md`, podniesienie o 1px.
- Karty tylko tam, gdzie jest przegląd. Nigdy na stronie notatki.

Kod: `Card.svelte`.
