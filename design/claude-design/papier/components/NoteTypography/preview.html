Całka Riemanna

Niech funkcja będzie ograniczona na przedziale domkniętym, f : [a, b] → ℝ. Jeśli jest ciągła, zachodzi podstawowe twierdzenie rachunku całkowego:

∫ab f(x) dx = F(b) − F(a)

W źródle Typst: $integral_a^b f(x) dif x$

  • funkcja pierwotna spełnia F′ = f,
  • całka nie zależy od wyboru funkcji pierwotnej.
„Całka to granica sum, a nie pole – pole to tylko interpretacja.”

Przybliżenie numeryczne, funkcja integrate():

def integrate(f, a, b, n=1000):
    h = (b - a) / n
    return h * sum(f(a + i * h) for i in range(n))
